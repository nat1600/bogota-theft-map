# Bogotá Theft Map 📊



¡Bienvenido al Mapa de Robos de Bogotá! Este proyecto visualiza datos de robos en la ciudad de Bogotá, Colombia, permitiendo a los usuarios identificar patrones, zonas de riesgo y tipos de crímenes reportados. Nuestro objetivo es proporcionar una herramienta útil para la conciencia ciudadana y el análisis de seguridad.

---

##  Características

* **Visualización interactiva:** Explora robos en un mapa dinámico.
* **Filtrado por tipo de delito:** Analiza robos de celulares, personas, vehículos, etc.
* **Filtrado por tiempo:** Visualiza datos por día, semana, mes o rangos de fechas.
* **Análisis de densidad:** Identifica las "zonas calientes" de criminalidad.
* **Datos actualizados:** Integra fuentes de datos para mantener la información relevante.
